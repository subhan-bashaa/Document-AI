Core Technology

How It Relates to Generative AI

Every core feature of DocuMind AI is a Generative AI concept applied in production.

Gen AI — LLM

🤖 Large Language Models

Google Gemini 2.5 Flash and Groq-hosted Llama/Qwen models generate natural language answers. These are state-of-the-art generative models that produce human-quality text on demand.

Gen AI — Embeddings

🔢 Text Embeddings

Google's text-embedding-004 model converts every text chunk into a 768-dimensional vector. This is a core Gen AI technique that lets the system understand meaning, not just keywords.

Gen AI — RAG Pattern

📚 Retrieval-Augmented Generation

RAG is the most important Gen AI design pattern for production systems. It grounds the generative model's output in real, verifiable data — eliminating hallucination.

Gen AI — Prompt Engineering

✍️ Prompt Engineering

A carefully crafted system prompt tells the LLM: "Answer ONLY from the provided context. Cite your sources. Don't use training data." This is a critical Gen AI skill for responsible systems.

Gen AI — Vector Search

🔍 Semantic Similarity Search

ChromaDB stores the embedding vectors and performs cosine similarity search — a foundational Gen AI infrastructure component that finds meaning-based matches, not just text matches.

Gen AI — Responsible AI

🛡️ Responsible AI Design

The system is architected to be transparent and trustworthy — a key principle in modern Gen AI. It provides source citations, refuses to hallucinate, and keeps API calls server-side.

Pipeline

RAG Pipeline — Step by Step

The complete flow from raw PDF to AI-generated, source-cited answer.

1

📄 PDF Upload & Storage

User uploads a PDF via the React frontend. Flask validates file type (PDF only) and size (max 16 MB), then saves it to the documents/ directory.

Tool: Flask · PyMuPDF · file_utils.py
2

✂️ Text Extraction

PyMuPDF (fitz) extracts raw text from every page of the PDF, preserving page numbers for later citation. Handles multi-page documents efficiently.

Tool: PyMuPDF · rag/loader.py
3

🔪 Text Chunking

Extracted text is split into overlapping ~500-token chunks. Overlap ensures context isn't lost at chunk boundaries — a critical technique for RAG quality.

Tool: rag/chunker.py
4

🔢 Embedding Generation (Gen AI)

Each chunk is converted into a 768-dimensional embedding vector using Google's text-embedding-004 model. This captures semantic meaning, not just words.

Tool: Google Generative AI · rag/embeddings.py
5

🗄️ Vector Storage (ChromaDB)

Embedding vectors are stored in ChromaDB along with metadata (source filename, page number, chunk text). ChromaDB persists this data to disk for future queries.

Tool: ChromaDB · rag/vectorstore.py
6

🔍 Semantic Retrieval (Gen AI)

User's question is embedded using the same model. ChromaDB performs cosine similarity search and returns the top-K most semantically relevant chunks.

Tool: ChromaDB · rag/retriever.py · Top-K=5
7

✍️ RAG Prompt Engineering (Gen AI)

A grounding prompt is built: "Answer ONLY from these document excerpts. Cite sources. Do not hallucinate." The top-K chunks are injected as context, with strict rules.

Tool: rag/generator.py · _build_rag_prompt()
8

✨ LLM Generation — Groq / Gemini (Gen AI)

The RAG prompt is sent to Groq (primary, ultra-fast: Llama/Qwen) or Google Gemini 2.5 Flash (fallback). The LLM generates a grounded natural-language answer from the context only.

Tool: Groq API · Google Gemini API · rag/generator.py
9

💬 Response with Source Citations

The answer + deduplicated source list (document name + page) is returned to the React frontend and displayed in the chat interface with source tags the user can verify.

Tool: routes/chat.py · ChatArea.jsx
Technology

Full Tech Stack

Every technology used, why it was chosen, and what role it plays.

⚛️
Frontend

React 18 + Vite 8

Component-based UI with hot-module replacement. Dark-themed, responsive layout with drag-and-drop PDF upload and real-time chat interface.

🐍
Backend

Python 3.10+ + Flask 3

Lightweight REST API. Blueprint-based routing, global JSON error handlers (400/404/405/413/500), CORS for React dev server, centralized config with .env validation.

G
LLM (Primary Fallback)

Google Gemini 2.5 Flash

State-of-the-art multimodal language model. Used for generating grounded answers when no Groq key is configured. Fast, reliable, and free-tier available.

⚡
LLM (Primary)

Groq API (Llama / Qwen)

Ultra-fast LLM inference. Tries multiple model candidates (openai/gpt-oss-20b, qwen/qwen3) with automatic fallback chain to Gemini if unavailable.

G
Embeddings (Gen AI)

Google text-embedding-004

Converts text chunks into 768-dimensional semantic vectors. Same model used for both document indexing and query embedding to ensure consistent similarity scoring.

🗄️
Vector Database

ChromaDB

Local vector database for semantic similarity search. Persists embedding vectors + metadata to disk. Supports filtering by document source for targeted queries.

📄
PDF Processing

PyMuPDF (fitz)

Extracts text from PDFs page by page with high fidelity. Preserves page numbers for source citation. Works on text-based PDFs (not scanned image-only PDFs).

💅
Styling

Vanilla CSS

Custom dark-theme design system using CSS variables. Glassmorphism cards, gradient text, subtle animations, and a fully responsive layout without external UI frameworks.

API

API Reference

All REST endpoints exposed by the Flask backend.

GET /api/health Server liveness check
Returns server status. Used by frontend to confirm backend is reachable. Returns 200 OK with status message.
GET /api/documents List all uploaded documents
Returns a JSON array of all indexed documents with ID, filename, page count, and upload timestamp.
POST /api/documents/upload Upload & index a PDF
Accepts multipart/form-data with a file field. Validates file type (PDF only) and size (max 16 MB). Triggers the full RAG indexing pipeline: extract → chunk → embed → store. Returns document ID and number of chunks indexed.

Errors: 400 (bad file) · 413 (too large) · 500 (indexing failed)
POST /api/chat RAG Q&A — full pipeline
Body: {"question": "...", "source_filter": "optional_file.pdf"}
Runs the full RAG pipeline: embeds question → retrieves top-K chunks → builds grounding prompt → calls Groq/Gemini → returns answer + source citations.

Max question length: 2000 characters.
Errors: 400 (bad question) · 503 (no docs indexed) · 500 (LLM failure)
POST /api/documents/{id}/summary AI document summary
Generates an AI summary of the entire specified document using the LLM. Returns a comprehensive text summary of the document's key topics and content.
